

# CIT Cricket Club

Welcome to the official web portal of the CIT Cricket Club. This platform is designed to connect cricket enthusiasts, announce upcoming inter-university fixtures, showcase tournament schedules, and allow students to seamlessly register for team trials and club memberships.

## Live Website
🔗 **Live Demo:** [https://iamabdulrafey-005.github.io/CIT331-cricket-club/](https://iamabdulrafey-005.github.io/CIT331-cricket-club/)

## Pages Included
- **Home (`index.html`):** Overview of the cricket club, announcements, mission, and highlights.
- **Events & Fixtures (`events.html`):** Upcoming matches, practice sessions, timings, and venues.
- **Registration (`register.html`):** Membership and trial registration form with client-side localStorage persistence.
