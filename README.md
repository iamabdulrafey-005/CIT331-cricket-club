

# CIT Cricket Club

Welcome to the official web portal of the CIT Cricket Club. This platform is designed to connect cricket enthusiasts, announce upcoming inter-university fixtures, showcase tournament schedules, and allow students to seamlessly register for team trials and club memberships.

## Live Website
 [https://iamabdulrafey-005.github.io/CIT331-cricket-club/](https://iamabdulrafey-005.github.io/CIT331-cricket-club/)

## Pages Included
Home (`index.html`): Overview of the cricket club, announcements, mission, and highlights.
Events & Fixtures (`events.html`):Upcoming matches, practice sessions, timings, and venues.
Registration (`register.html`): Membership and trial registration form with client-side localStorage persistence.

## Project Structure & Features

- Home Page (`index.html`): Features hero section, quick overview of the club, upcoming fixtures, and modern responsive navigation.
- Events Schedule (`events.html`): Displays upcoming match schedules, practice sessions, and tournament dates in structured cards.
- Registration Portal (`register.html`): Accessible registration form with real-time browser storage integration using JavaScript `localStorage`.
- Styling (`style.css`): Pure CSS responsive layout implemented via CSS Grid and Flexbox with mobile-first breakpoints.
- W3C Standards: Validated HTML5 code adhering strictly to modern semantic standards without syntax errors.
